# 01 - Random Walks and Filtrations

## 1. Random variables indexed by time

A stochastic process is a family of random variables

```text
X = (X_t)_{t in T}
```

indexed by time. In this project, the starting point is discrete time:

```text
T = {0, 1, 2, ...}
```

The canonical example is the symmetric random walk:

```text
S_0 = 0
S_n = X_1 + ... + X_n
P(X_i = 1) = P(X_i = -1) = 1/2
```

Each increment is independent and has expectation zero.

## 2. Information through time

Probability theory becomes dynamic once we ask what is known at each time.

A filtration is an increasing sequence of sigma-algebras:

```text
F_0 subset F_1 subset F_2 subset ...
```

The interpretation is simple: `F_n` contains all information revealed up to time `n`.

For a random walk, the natural filtration is

```text
F_n = sigma(X_1, ..., X_n)
```

or equivalently the information generated by the path up to time `n`.

## 3. Adapted processes

A process `(Y_n)` is adapted to `(F_n)` if `Y_n` is known at time `n`.

For the random walk, `S_n` is adapted because it is determined by the first `n` increments.

This is a small definition with large consequences. A trading rule, stopping rule, forecast, or signal is only meaningful dynamically if it respects available information. It cannot depend on tomorrow's increment today.

## 4. Why this matters

Filtrations separate two ideas that are often blurred:

1. the random object itself;
2. the information available to an observer at a given time.

This distinction is the foundation for martingales, stopping times, stochastic integration, and eventually much of modern quantitative finance.
